# Openlet

## Platform

web

## Users and purpose

People and teams work with persistent Leta agents in a workspace. Each person has a private conversation with an agent; permitted owners can inspect its Activity. Agents delegate work to Leti agents, use files and tools, and receive scheduled work and questions/requests.

## Capabilities and constraints

Storage includes personal, team, agent and conversation storage. A dedicated computer is not required for chat and cloud storage. A future computer tier is planned, not a current marketing claim. Clerk handles accounts. Onboarding already provisions the first workspace. Pricing and quotas have not been supplied for the public site.

## Brand commitments

The user explicitly chose to port OpenBot's layouts and interactions, using Openlet's blue mark, existing shadcn semantic variables and Tailwind. Public pages retain OpenBot's dark appearance. App themes and established workspace UI remain independent.
